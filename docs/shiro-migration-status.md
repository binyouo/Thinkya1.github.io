# Shiro 迁移状态

本站从 Hexo 迁至 Shiro，当前上游对照版本为 [Innei/Shiro `891bb24`](https://github.com/Innei/Shiro/commit/891bb24)。
仓库保留 Shiro 的前端和许可声明，在数据层适配本地 Markdown。对照范围为公开仓库源码。

## 当前部署选择

用户目前没有独立服务器，本站继续使用 Vercel 和 Markdown + Git 写作。
Shiro 的原版前端依赖 Mix Space Core；完整部署 Core 还需要后端运行环境及数据库。
本次采用 Next.js 同源只读兼容 API，文章和页面随应用一起部署，服务端渲染直接读取本地内容。
这套兼容层没有实现完整的 Mix Space CMS，也不会持久化访客提交的数据。

内容目录是 `apps/web/content/posts` 和 `apps/web/content/pages`，图片位于
`apps/web/public`。Obsidian vault 位于 `apps/web/content`。后续文章修改通过 Git 提交和重新部署发布。

## 功能范围

| 功能 | 当前接入方式或限制 |
| --- | --- |
| 首页、文章列表与详情 | 从 Markdown 生成 Shiro 需要的文章数据，保留正文、标题、日期和个人资料 |
| 分类、标签、分页与排序 | 只读内容接口提供列表和筛选 |
| 搜索与文章时间线 | 使用仓库内文章，不包含不存在的日记或动态数据 |
| 关于等独立页面 | 读取 `content/pages` |
| RSS | 输出文章正文，图片和链接转换为绝对 URL，关闭评论的文章不显示评论入口 |
| Sitemap 与 robots | 提供本站可访问内容的搜索引擎入口 |
| 旧 Hexo 地址 | 重定向到对应 Shiro 文章地址 |
| 深浅主题、阅读目录及前端交互 | 保留 Shiro 实现；已验收目录跳转、搜索和手机导航，主题切换未逐项复测 |
| 评论、登录、点赞、阅读计数 | 尚未接入持久化服务；不能把固定数值或成功响应当作真实记录 |
| 邮件订阅、实时在线状态 | 尚未配置邮件或实时服务，RSS 订阅可独立使用 |
| 日记、说说、动态、友链、项目 | 尚无对应内容源，现有前端代码不代表这些功能已经可用 |

如需完整 CMS 能力，后续应部署 Core、数据库及需要的邮件和实时服务，再导入现有文章、
替换当前本地内容请求适配器、配置 API 地址并逐项启用对应入口。仅打开前端开关不会补上持久化能力。

## 阅读导轨

文章桌面侧栏按提供的截图改为细线、暖金色弯曲游标、主章节圆点，以及当前章节名和阅读百分比。
圆点可直接跳转；鼠标移入右侧导轨区域，导轨淡出并原位显示无边框目录、圆形进度、回到顶部和分享入口。
移出后延迟收起，快速重入取消收起。目录强调当前章节，长目录只在内部滚动，打开时让当前章节保持可见。
键盘和点击也可展开，Escape 关闭并返回触发按钮；隐藏目录不可聚焦，减少动态效果时禁用展开/收起过渡。
没有章节的文章只显示进度。
滚动复用现有页面状态，章节位置随正文尺寸变化重新测量；监听标题节点替换，避免正文刷新后继续读取已脱离文档的节点。
跳转直接定位，避免途中懒加载图片改变平滑滚动的目标位置。

验证：TypeScript 与生产构建通过，范围内 ESLint 无错误（TocAside 保留 2 条既存警告）。
Chrome 已检查桌面滚动、目录和圆点跳转（标题位于视口顶部约 100px）、键盘展开/关闭、末尾 100%、

悬停补齐后另行验证移入展开、移出收起、快速重入、悬停目录跳转、Escape 后 Enter 重开、回到顶部，
