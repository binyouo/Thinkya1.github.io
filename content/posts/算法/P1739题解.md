# P1739 表达式括号匹配（[洛谷题面](https://www.luogu.com.cn/problem/P1739)）

## 题目

题目描述：

假设一个表达式有英文字母（小写）、运算符（`+`、`-`、`*`、`/`）和左右小（圆）括号构成，以 `@` 作为表达式的结束符。请编写一个程序检查表达式中的左右圆括号是否匹配，若匹配，则输出 `YES`；否则输出 `NO`。表达式长度小于 $255$，左圆括号少于 $20$ 个。

输入格式：

一行：表达式。

输出格式：

一行：`YES` 或 `NO`。

数据范围与说明：

表达式长度小于 $255$，左圆括号少于 $20$ 个。

输入输出样例 #1

输入：

```
2*(x+y)/(1-x)@
```

输出：

```
YES
```

输入输出样例 #2

输入：

```
(25+x)*(a*(a+b+b)@
```

输出：

```
NO
```

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
string s;
stack <int> stk;
int main(){
    int i=0;
    getline(cin,s);
    while(s[i]!='@')
    {
        if(stk.empty()){    
            if(s[i]==')'){
                cout<<"NO";
                return 0;
            }
        }
        if(s[i]=='('){
            stk.push(s[i]);
        }
        if(s[i]==')'){
            stk.pop();
        }
        i++;
    }
    if(stk.empty()){
        cout<<"YES";
    }else {
        cout<<"NO";
    }
    return 0;
}
```
